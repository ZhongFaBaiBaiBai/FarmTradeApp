# 农产品买卖记录

面向农户的买卖记账 App。拍照识别秤单、整本记录本批量录入、手动记账三合一，数据全部存在手机本地，不联网、不上传。

## 功能

| 模块 | 能做什么 |
| --- | --- |
| 拍照记录 | 拍一张秤单，自动识别总重/车重/单价/日期，生成待确认记录 |
| 拍记录本 | 一张照片识别整页「总重 − 车重」算式，批量生成多行待确认 |
| 手动批量 | 一次填多行，适合补录 |
| 手动记账 | 逐项填写：方向、类型、计量方式、重量/数量、单价 |
| 记录列表 | 按买入/卖出、时间范围筛选；按日期搜索；多种排序（时间 / 类型→单价 / 日期→类型→单价）；批量勾选删除 |
| 分组视图 | 日期 → 类型 → 单价 三级分组，单价组可折叠 |
| 图表 | 日/月/季/年 趋势折线图 + 买卖对比柱状图 |
| 汇总 | 按日/月/季/年统计买入、卖出、净收益、净重总和、类型明细 |
| 数据 | 导出 Excel（查看用）、导出/导入 JSON（换机合并）、清空数据 |

## 计量规则

- **按重量（公斤）**：总额 = 净重(公斤) × 2 × 单价
- **按重量（斤）**：总额 = 净重(斤) × 单价
- **按数量**：总额 = 数量 × 单价

净重 = 总重 − 车重。

## 界面

- 统一设计系统：`colors.xml` / `dimens.xml` / `styles.xml` 集中管理，布局里不再散落硬编码色值
- 渐变页头 + 大圆角卡片 + 柔和阴影
- 矢量图标全套替换系统 `ic_menu_*` 老图标
- 胶囊标签、分段按钮、Chip 筛选统一圆角规范

## 构建

推送到 `main` 会自动触发 GitHub Actions 构建，产物在 Actions → Artifacts → `FarmTradeApp-debug-apk`。

本地构建：

```bash
gradle assembleDebug
```

需要 JDK 17 + Android SDK 34。

## 技术栈

- Kotlin + AndroidX，`minSdk 24` / `targetSdk 34`
- 视图层：Activity / Fragment + ViewBinding
- 存储：SQLite（`SQLiteOpenHelper`，库文件 `farm_trade.db`）
- 图表：MPAndroidChart
- OCR：Google ML Kit 中文文字识别（离线）

## 数据与隐私

- 所有记录保存在本机 `/data/data/com.farmtrade.app/databases/farm_trade.db`
- 拍照原图只用于识别，识别后可自行清理
- 没有任何网络请求
