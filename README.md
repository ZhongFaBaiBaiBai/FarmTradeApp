# 家庭农场管理（FarmTradeApp）

一个装在手机里的家庭账本，给自家收粮、卖粮、买农资用。单据、地块、种子包装可以拍照存下来，写一句注释；几袋化肥、干了几天活、雇了几个小时工，也能按数量记一笔。

没有账号，没有服务器，没有广告，装好就能用，不联网也不影响记账。

## 功能一览

| 页面 | 能做什么 |
| --- | --- |
| 记录 | 买卖流水、组合筛选、按日期搜索、分组排序、批量删除 |
| 汇总 | 按日 / 月 / 季 / 年统计笔数、金额、净重和品类明细 |
| 图片 | 存单据、地块、种子包装照片并写注释；也可以记纯文字笔记 |
| 设置 | 导出表格（CSV，Excel 打开）、导出 / 导入 JSON、清空记录 |

## 记录

- 买卖方向：买入 / 卖出
- 类型：内置小麦、玉米、水稻、大豆、化肥、农药、柴油等，不够用可以自己加
- 三种计量方式：
  - **按公斤**：填总重、车重，净重自动算；单价按元/斤填
  - **按斤**：填总重、车重；单价按元/斤填
  - **按数量**：填数量和单位，单位自己写——袋、桶、件、天、小时都行
- 金额随输入实时计算，不用另外按计算器
- 列表上方有汇总卡：当前筛选结果的买入、卖出、净额，以及各类型的金额
- 筛选：全部 / 买入 / 卖出、日期范围（全部时间 / 今天 / 本月 / 本季 / 本年 / 自定义）、年份、货物类型；搜索可以直接输 `2025-08`、`2025-08-15` 或 `08-15`
- 排序：默认按年份分组，也可以按「类型 → 单价」或「日期 → 类型 → 单价」排，单价支持升序降序
- 点一条记录进编辑页修改，长按删除；点「管理」可以多选批量删除

## 拍照记账

记录页右下角「+」→「拍照记录」，对着收粮点打印的过磅单拍一张。识别成功会带出：

- 粮食类型（如小麦）
- 毛重、皮重（公斤）
- 单价（元/斤）
- 过磅时间

当天已经记过一笔的话，车重、单价、买卖方向会沿用上一条，少填几项。识别结果不会直接入库，先给一张确认卡：每个字段旁边标着「拍照」「沿用」还是「已改」，点哪一行改哪一行，确认无误再保存。

也可以「从相册选图」，把之前拍好的单子导进来识别。

识别前会做几轮图像处理：裁纸、放大、灰度增强、Otsu 二值化、±12° 旋转重试，哪一版能认出完整字段就用哪一版。打印清楚、正对拍摄的单子比较稳；地磅 LED 屏和手写单不行——试过针对 LED 屏的裁切、反色、二值化和七段数码管模板匹配，实际还是不够用，识别不出来会提示重拍或转手动录入。

## 手动录入

- **手动记账**：完整表单，适合单笔慢慢填
- **手动批量**：一次开多行，每行只填总重和车重，整批共用方向、类型、单位、单价；保存时每行时间自动错开 1 分钟

## 图片与笔记

「图片」页放的是跟农活有关、但不必进流水的照片：

- 收粮点开的单子、地磅读数，拍下来存底
- 地块、仓库、装车现场，以后好对账
- 种子、化肥、农药的包装袋，注释写「济麦22 麦种」「玉米种 先玉335」
- 纯文字笔记，比如「东地 3 亩，明年种花生」

用法：右下角「+」→ 拍照 / 从相册选图 / 写一条文字笔记。图片卡片下面那行就是注释，点一下就能改。点照片全屏查看，支持双指缩放、双击放大、单指拖动。长按删除照片，注释一起删掉。

照片存在应用私有目录 `files/receipts/`，注释和文字笔记存在 SQLite 的 `photo_notes` 表里。

## 汇总

「汇总」页用文字和数字直接列账：

- 日 / 月 / 季 / 年四种周期，左右箭头翻页
- 点日期标题，直接列出有记录的日期 / 月份 / 年份，跳过去
- 可以只看拍照识别的，或只看手动录入的
- 可以按货物类型筛选
- 本期合计：记录笔数、净额（卖出 − 买入）、买入合计、卖出合计
- 下面按类型、按时间列明细：笔数、净重、金额

## 金额怎么算

| 计量方式 | 输入 | 金额 |
| --- | --- | --- |
| 按公斤 | 总重、车重（公斤），单价（元/斤） | 净重(公斤) × 2 × 单价 |
| 按斤 | 总重、车重（斤），单价（元/斤） | 净重(斤) × 单价 |
| 按数量 | 数量、单位、单价 | 数量 × 单价 |

净重 = 总重 − 车重。

公斤模式之所以乘 2，是因为收粮点一般按斤报价、地磅按公斤称重，1 公斤 = 2 斤，先把公斤折成斤再乘单价。

## 数据与备份

- 数据库：`/data/data/com.farmtrade.app/databases/farm_trade.db`
- 图片：`/data/data/com.farmtrade.app/files/receipts/`
- 应用自身不联网、不上传；OCR 用的是 ML Kit 自带的中文离线模型，不需要下载语言包
- **导出 CSV**：UTF-8 带 BOM，Excel / WPS 打开中文不乱码，适合看和打印
- **导出 JSON**：全部记录 + 自定义类型，换手机时在新手机导入，内容完全相同的记录会自动跳过
- JSON 不包含照片、图片注释和文字笔记，照片要另外拷
- 「清空数据」只清交易记录，不动图片和笔记

## 构建

推送到 `main` / `master` 会自动触发 GitHub Actions，构建好的 APK 在 Actions → 对应运行 → Artifacts → `FarmTradeApp-debug-apk`。

本地构建：

```bash
gradle assembleDebug
```

需要 JDK 17 + Android SDK 34。签名固定用 `app/debug.keystore`，同一把钥匙覆盖安装不会丢数据。

## 技术栈

- Kotlin + AndroidX，`minSdk 24` / `targetSdk 34`，当前 `versionName 1.3`
- 界面：Activity / Fragment + ViewBinding，底部四个页签
- 存储：SQLite（`SQLiteOpenHelper`，`farm_trade.db`）
- OCR：Google ML Kit `text-recognition-chinese:16.0.0`（离线）
- 图片加载：Glide；异步：Kotlin Coroutines

## 已知限制

- 只有收粮点打印的过磅单识别效果较好；地磅 LED 显示屏、手写单据识别率低
- 单机应用，没有云同步和多设备共享，换手机靠 JSON + 手动拷图片
- JSON 导出不含图片、图片注释和文字笔记
- 想继续提升识别效果，可以换更强的 OCR 引擎，或让更强的模型重做预处理
